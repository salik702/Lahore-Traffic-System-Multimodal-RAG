# Manual verification photographs

These openly licensed images were obtained for manual checks. None supplies hardcoded API results. The originals were resized to at most 1920px and recompressed; annotated derivatives contain actual model boxes. Older baseline derivatives redact plates, while the upgraded dashboard and reports retain visible plate evidence. Derivatives, including the downloaded verification report, retain the original image license.

Foreign samples verify inference execution, not Punjab jurisdiction or enforcement. These files are private local demonstration artifacts and have no public media route.
